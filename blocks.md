# Blocks (shadcn registry)

Prebuilt, copy-into-your-project blocks — dropzone, avatar uploader, multi-file upload form, S3 direct-upload — installable via the shadcn CLI's [GitHub registry](https://ui.shadcn.com/docs/registry/github) support, no separate registry server required:

```sh
npx shadcn@latest add autorender/react-mediadrop/dropzone
```

Swap `dropzone` for `avatar-uploader`, `multi-file-upload-form`, or `s3-direct-upload`. (Shorter `@mediadrop/dropzone` form pending shadcn Registry Directory review.)
